# IoT Intrusion Detection System using Machine Learning

This project implements a Machine Learning-based Intrusion Detection System (IDS)
for IoT network traffic classification.

## Project Description
The model is trained on the RT-IoT2022 dataset to classify different types of network
traffic and cyber-attacks using Machine Learning algorithms.

## Files
- `app.py`: Streamlit web application
- `final_model.pkl`: Trained Machine Learning model
- `requirements.txt`: Required Python libraries

## Deployment
The model is deployed using Streamlit Cloud.
